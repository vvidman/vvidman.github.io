InferRouter · Part 3

Secret management

Where API keys live — and why the key is read fresh on every request.

Environment variables
Visible in docker inspect. A container restart is needed to rotate.
Config files
One careless git add away from being public.
Docker Secrets
Mounted as files at /run/secrets/. Never in environment variables or config files.
Every request
SecretReader reads /run/secrets/ directly.
Key lives on the stack
Never stored in a field.
Discarded
When the call completes.
Overwrite the file on the host, and the updated key is read without restarting the container.
