VCS as proof store

Why duplicate source content into a proof database when source control already tracks everything?

Traditional RAG over a codebase
Two copies of everything
An ongoing sync obligation
A proof store you have to maintain yourself
SourceRAG
No source content is stored outside the repository
The vector store holds only embeddings and metadata
File content is reconstructed on demand from the VCS
Revision + file path
Taken from the vector store payload.
VCS call
Asked for that revision of the file.
Exact content
As it existed at that commit.
The proof isn't a database row — it's a commit in your repository's history.
