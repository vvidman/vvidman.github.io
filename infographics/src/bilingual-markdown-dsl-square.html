Site Generator · Part 2

Designing a minimal DSL
for bilingual Markdown content

One file. Two languages. No duplication.

:::section intro :::lang en Markdown :::lang :::lang hu Markdown :::lang :::section
One file per article
Not one file per language. Not a source file with a translation sidecar.
Two levels, not one
:::section name — a named content block. :::lang en / :::lang hu — a language block inside a section.
A simple state machine
The parser reads line by line. No regex. No recursive descent.
Explicit over clever.
