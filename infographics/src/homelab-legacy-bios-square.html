The Legacy BIOS + GPT trap

Why older machines refuse to boot after a successful Linux installation.

GPT partition table
Modern installers default to GPT, even in Legacy BIOS mode.
GRUB installs correctly
boot.img in the MBR, core.img in the bios_grub partition.
BIOS hand-off fails
Some older BIOSes don't reliably run this boot chain from a GPT disk.
Boot Device Not Found
After a seemingly successful installation.
Ubuntu Server (Subiquity)
Only creates GPT partition tables
No option to choose MBR/DOS
grub-install succeeds, the system still won't boot
Debian classic installer
Explicitly supports MBR/DOS partition tables
GRUB installs to the MBR gap
The system will boot on first try
GRUB is not the problem. The problem lives in the BIOS firmware, not in the bootloader.
