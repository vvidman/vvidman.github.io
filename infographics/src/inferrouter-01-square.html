One endpoint, any provider

A single self-hosted proxy with strategy-based inference routing.

Callers
Speak the OpenAI chat completions API they already use.
InferRouter
One OpenAI-compatible endpoint. A configurable strategy routes each request.
Cloud providers
One or more. Any OpenAI-compatible HTTP endpoint qualifies.
Local model · LlamaSharp
Runs in-process. Handles the call when all providers are unavailable or exhausted.
API keys scattered
No single place to rotate a key or audit access.
Routing logic reimplemented
Writing it once per project means maintaining it N times.
Provider changes cascade
Swapping a provider meant touching every project that used it.
Provider management is infrastructure.
Infrastructure belongs in one place.
